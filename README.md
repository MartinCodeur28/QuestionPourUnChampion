# 🎬 QVGDM French - Qui Veut Gagner Des Millions?

An interactive quiz game inspired by the famous French game show "Qui veut gagner des millions" (Who Wants to Be a Millionaire).

## 🎮 Play Now
**Open the project repository here:** https://github.com/MartinCodeur28/QuestionPourUnChampion

From there, you can browse the XML files and choose a quiz to use in the game.

---

## 📖 What Is This?

This is a fun, interactive quiz game where you:
- Answer multiple-choice questions
- Progress through difficulty levels
- Use lifeline features (50/50, phone, audience poll)
- Try to reach 1 million euros!

The game displays a countdown of money prizes as you advance through questions.

---

## 🎯 How to Play

1. Open the game link above in your web browser
2. Read each question carefully
3. Click on your answer (A, B, C, or D)
4. If correct → advance to the next question and win the prize
5. If incorrect → game over (you can restart)

### 💡 Using Lifelines (Jokers)

You have 3 special lifelines you can use once each:

- **🔸 50/50** - Removes 2 wrong answers, leaving only 2 choices
- **📞 Phone** - Call someone for help
- **📊 Poll** - See what the audience thinks

Click the icons at the top to use them!

## ✨ NEW: Create Your Own Quiz!

### 🌐 **No Programming Required!**

The easiest way to create a new quiz is to use our **Quiz Generator** tool:

#### Step-by-Step Instructions:

1. **Open the Quiz Generator**
   - Click here: [Open Quiz Generator](quiz-generator.html)
   - Or find the file named `quiz-generator.html` on your computer and open it in your browser

2. **Fill in Your Quiz Details**
   - Enter a name for your quiz (e.g., "History Quiz", "Science Facts", etc.)
   - This name will appear when people play your quiz

3. **Add Your First Question**
   - Type the question in the large box
   - Example: "What is the capital of France?"
   
4. **Add the Correct Answer**
   - Type the right answer
   - Example: "Paris"

5. **Add Three Wrong Answers**
   - Fill in three incorrect answers to make the question challenging
   - Examples: "London", "Berlin", "Madrid"

6. **Click "➕ Add Question"**
   - Your question is now added to the quiz
   - The form clears so you can add another question

7. **Repeat Steps 3-6**
   - Add as many questions as you want!
   - Tip: 10-15 questions is a good quiz length

8. **Download Your Quiz**
   - Once done, click **"⬇️ Download XML"** to save it as a file
   - This file stores your questions and can be shared with others
   - OR click **"🌐 Generate HTML"** to create a standalone quiz file that anyone can play immediately

### 📥 How to Use Your Downloaded Quiz

**Option A: XML File (Advanced)**
- Share the XML file with others
- They can upload it in the Quiz Generator or main game using the "Quiz:" upload button

**Option B: HTML File (Recommended)**
- The HTML file is a complete, standalone quiz
- Anyone can open it directly - no setup needed!
- Perfect for sharing with friends, family, or students

## 🎓 Tips for Creating Good Quizzes

✅ **DO:**
- Use clear, simple question wording
- Make wrong answers realistic (not obviously wrong)
- Mix different topics for variety
- Test your quiz before sharing
- Add questions gradually to avoid mistakes

❌ **DON'T:**
- Leave fields empty - all 4 answers are required
- Use very long questions (keep them concise)
- Make all wrong answers too similar
- Add numbers that are too large (they might be hard to read on screen)

## ❓ Frequently Asked Questions

**Q: Can I edit a quiz after downloading it?**
A: Yes! Use the "Import" section in the Quiz Generator to upload your XML file and make changes.

**Q: What format should my answers be in?**
A: Any format works! Numbers, letters, names, dates, etc. Keep answers reasonably short.

**Q: How do I share my quiz with others?**
A: 
- Download as HTML and email it, or
- Upload to Google Drive, Dropbox, or any file-sharing service

**Q: Can multiple people play the same quiz?**
A: Yes! Everyone can use the same HTML or XML file.

**Q: What if I make a mistake in my quiz?**
A: Use the Quiz Generator to import your file, delete the wrong question, and download again.

**Q: Do I need to install anything?**
A: No! Everything works directly in your web browser.
